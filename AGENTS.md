## 1. Executive Summary & Product Vision (Обзор проекта и концепция)

### 1.1 Контекст и миссия проекта
**FocusGlass** — это интерактивная десктопная система биологической обратной связи (БОС / Biofeedback), разрабатываемая по кейсу научно-медицинской фирмы **ООО НМФ «Нейротех»**.

В основе продукта лежит беспроводной нейроинтерфейс **BrainBit**, регистрирующий биопотенциалы головного мозга (электроэнцефалограмму — ЭЭГ) по 4 каналам в реальном времени. FocusGlass преобразует эти сигналы в динамический полупрозрачный экранный оверлей («окно-фильтр»), отображаемый поверх любого пользовательского окружения (среда разработки IDE, браузер, CAD-системы, офисные пакеты, игры).

### 1.2 Замкнутый контур биологической обратной связи (БОС)
Классическая проблема умственного труда — «незаметное» рассеивание внимания (mind wandering) и накопление когнитивной усталости. Человек не замечает, как теряет фокус, пока не проходит 20–40 минут непродуктивного времени.

```
       ┌────────────────────────────────────────────────────────┐
       │                 Пользователь за ПК                     │
       └──────────────────────────┬─────────────────────────────┘
                                  │ 1. Излучение биопотенциалов мозга
                                  ▼
       ┌────────────────────────────────────────────────────────┐
       │   BrainBit Headband (4 электрода: T3, T4, O1, O2)      │
       └──────────────────────────┬─────────────────────────────┘
                                  │ 2. Сырой ЭЭГ-поток (250 Гц, BLE 4.0/5.0)
                                  ▼
       ┌────────────────────────────────────────────────────────┐
       │   FocusGlass Rust Core (Tauri v2 + NeuroSDK2 / Sim)    │
       │   - Фильтрация артефактов (моргания EOG, сжатия EMG)   │
       │   - БПФ / Оценка ритмов (Альфа 8-13 Гц, Бета 14-30 Гц)  │
       │   - Индексы концентрации (%) и релаксации (%)          │
       └──────────────────────────┬─────────────────────────────┘
                                  │ 3. Вектор метрик & статус (IPC)
                                  ▼
       ┌────────────────────────────────────────────────────────┐
       │   Liquid Glass Overlay & HUD («шкала-столбик»)         │
       │   - Уровень фокуса < Порога: плавное затемнение экрана │
       │   - Уровень фокуса >= Порога: кристальная прозрачность │
       │   - Нажатия мыши и клавиатуры проходят «насквозь»      │
       └──────────────────────────┬─────────────────────────────┘
                                  │ 4. Подсознательная визуальная коррекция
                                  ▼
       ┌────────────────────────────────────────────────────────┐
       │         Возврат когнитивной концентрации               │
       └────────────────────────────────────────────────────────┘
```

- **Режим концентрации (Focus Mode)**: Целевая метрика — бета-активность. При падении индекса концентрации ниже заданного пользователем порога (например, 60%), экран плавно затемняется (dimming/blur), давая неинтрузивный стимул мозгу собрать внимание. При восстановлении концентрации экран возвращается к 100% прозрачности.
- **Режим релаксации (Calm Mode)**: Целевая метрика — альфа-активность. Используется для снятия стресса и медитативных пауз. Рост психоэмоционального напряжения вызывает затемнение экрана, мотивируя пользователя замедлить дыхание.
- **Сквозное взаимодействие (Click-Through)**: Оверлей не блокирует работу за компьютером — курсор и клавиатурный ввод беспрепятственно передаются в активные программы (`WS_EX_TRANSPARENT`).

## 2. Hardware Specifications & Neurophysiological Model (Нейрофизиология и BrainBit)

### 2.1 Аппаратные характеристики BrainBit
- **Электроды**: 4 сухих позолоченных подпружиненных электрода, расположенных по международной системе 10-20:
  - **T3, T4** — левая и правая височные зоны (Temporal lobes);
  - **O1, O2** — левая и правая затылочные зоны (Occipital lobes);
  - Референтный и заземляющий контакты расположены на лобной ленте.
- **Частота дискретизации (Sampling Rate)**: **250 Гц** (каждые 4 мс поступает вектор измерений).
- **Разрядность АЦП**: 24 бит, с динамическим диапазоном входного сигнала до $\pm 375$ мВ.
- **Интерфейс связи**: Bluetooth Low Energy (BLE 4.0 / 5.0).
- **Мониторинг контакта (Impedance / Resistance)**: Аппаратное измерение сопротивления перехода электрод-кожа в килоомах для каждого из 4 каналов.

### 2.2 Спектральные диапазоны и математика метрик
Emotions SDK (и встроенный математический симулятор FocusGlass) оперирует разделением спектра ЭЭГ на стандартные физиологические диапазоны:

| Ритм | Частотный диапазон | Физиологическое значение | Роль в FocusGlass |
|---|---|---|---|
| **Дельта ($\delta$)** | 0.5 — 4.0 Гц | Глубокий сон, патологическая заторможенность | Индикатор сонного состояния / смещения электродов |
| **Тета ($\theta$)** | 4.0 — 8.0 Гц | Дремота, глубокая релаксация, рассеянность | Рост $\theta$ при падении $\beta$ — признак прокрастинации |
| **Альфа ($\alpha$)** | 8.0 — 13.0 Гц | Спокойное бодрствование, закрытые глаза | База для **Индекса Релаксации** (Calm Index) |
| **Бета ($\beta$)** | 14.0 — 30.0 Гц | Активная интеллектуальная работа, фокус | База для **Индекса Концентрации** (Focus Index) |
| **Гамма ($\gamma$)** | 30.0 — 50.0 Гц | Высокая когнитивная интеграция, инсайты | Контроль когнитивного гипертонуса |

#### Формула индекса концентрации ($I_c$)
Индекс концентрации рассчитывается через отношение мощности высокочастотной ритмики ($\beta$) к медленноволновой активности ($\theta + \alpha$) с нормализацией относительно индивидуального базового уровня (baseline), полученного в процессе калибровки:
$$I_c(t) = \frac{P_\beta(t)}{P_\theta(t) + P_\alpha(t)} \cdot K_{\text{calib}}$$
Значение приводится к диапазону $0 \dots 100\%$ со скользящим экспоненциальным сглаживанием ($\tau = 1.0 \dots 5.0$ с).

### 2.3 Фильтрация артефактов
- **Миографические артефакты (EMG)**: Вызываются сжатием челюстей и мимикой (высокоамплитудные всплески $>50$ Гц). При их детекции обновление прозрачности БОС временно замораживается во избежание ложных затемнений.
- **Окулографические артефакты (EOG)**: Моргания и движения глазных яблок (низкочастотные скачки в височных каналах T3/T4). Отсекаются специализированным пороговым фильтром.

## 3. Technology Stack & System Architecture (Стек технологий и архитектура)

### 3.1 Общий обзор стека
Проект использует современный, высокопроизводительный и легковесный стек:

| Компонент | Технология | Обоснование выбора |
|---|---|---|
| **Десктопный движок** | **Tauri v2 (Rust)** | Потребление памяти $<40$ МБ (в 8-10 раз легче Electron), мгновенный запуск, прямое управление Win32 API окнами. |
| **Ядро бэкенда** | **Rust (Edition 2024)** | Потокобезопасная обработка 250 Гц потока данных, `libloading` для работы с DLL без C++ рантайма, ультранизкая задержка. |
| **UI Фреймворк** | **React 19 + TypeScript** | Декларативное управление состоянием, React Compiler, компонентная модульность, строгая типизация. |
| **Сборщик фронтенда** | **Vite 6** | Мгновенный HMR (hot module replacement) $<50$ мс, идеальный dev-experience. |
| **Дизайн-система** | **Tailwind CSS v4 + Liquid Glass** | Аппаратно-ускоренные фильтры размытия (`backdrop-filter`), кастомные glassmorphism токены, спекулярные блики. |
| **Осциллограф ЭЭГ** | **HTML5 Canvas 2D (60 FPS)** | Прямой рендеринг волн 4 каналов без нагрузки на React Virtual DOM. |
| **Иконки** | **Lucide React** | Минималистичный премиальный набор векторных иконок. |
| **Интеграция с железом** | **NeuroSDK2 (C API / FFI)** | Официальный SDK BrainBit (`neurosdk2.dll`), кроссплатформенный Bluetooth LE слой. |
| **Генератор симуляции** | **In-Engine Synthetic EEG (Rust/TS)** | Автономный математический симулятор 250 Гц для презентации без физического ободка. |

### 3.2 Архитектура окон в Tauri v2
Приложение FocusGlass функционирует в двух режимах (двухоконная или адаптивная архитектура):

1. **Overlay Window (`overlay`)**:
   - Флаги: `transparent: true`, `decorations: false`, `alwaysOnTop: true`, `fullscreen: false` (или растянут на экран).
   - Сквозной клик: `window.set_ignore_cursor_events(true)` (на Windows активирует `WS_EX_TRANSPARENT | WS_EX_LAYERED`).
   - Отображает: фоновый виньеточный светофильтр затемнения + компактный плавающий HUD («шкала-столбик»).
2. **Dashboard / Settings Window (`main`)**:
   - Полнофункциональная панель управления: настройка порогов, выбор устройства (Bluetooth vs Simulator), калибровка, 4-канальный осциллограф, аналитика сессии.
   - Вызывается горячей клавишей (`Ctrl+Shift+G` / `Cmd+Shift+G`) или через системный трей.

### 4.2 Стилистические принципы «Liquid Glass»
1. **Multi-layer Glassmorphism**: Использование глубокого `backdrop-filter: blur(24px)` с повышенной насыщенностью (`saturate(190%)`), предотвращающей выцветание интерфейса над пестрыми обоями или кодом.
2. **Specular Bevels (Грани преломления)**: Тончайшие внутренние тени (`inset 0 1px 0 rgba(255,255,255,0.3)`) создают физически корректную кромку полированного кварцевого стекла.
3. **Fluid Gradients & Ambient Glows**: Элементы активного состояния излучают неоновое свечение в цветах `#FF6600` (BrainBit) и `#00D2FF` (Focus).
4. **Минималистичный HUD («шкала-столбик»)**:
   - Вдохновлен слайдами 4 и 5 презентации ООО НМФ «Нейротех».
   - Компактная вертикальная или горизонтальная капсула с индикатором заполнения жидким стеклом.
   - Пульсирующий неоновый индикатор текущего процента фокуса.

## 6. TypeScript Data Contracts & Interfaces (Интерфейсные контракты)

### 6.1 Телеметрия ЭЭГ и состояние электродов
```typescript
/** Потоковый пакет данных ЭЭГ с частотой 250 Гц */
export interface EEGTelemetryPacket {
  timestamp: number;                  // Временная метка (мс)
  rawChannels: {
    t3: number;                       // Микровольты (мкВ) [-500 .. +500]
    t4: number;
    o1: number;
    o2: number;
  };
  spectrum: {
    delta: number;                    // 0.5 - 4 Гц (мкВ^2 / Гц)
    theta: number;                    // 4 - 8 Гц
    alpha: number;                    // 8 - 13 Гц
    beta: number;                     // 14 - 30 Гц
    gamma: number;                    // > 30 Гц
  };
  metrics: {
    concentration: number;            // Индекс фокуса: 0 - 100%
    relaxation: number;               // Индекс расслабления: 0 - 100%
  };
  electrodes: {
    t3: ElectrodeStatus;              // Качество контакта
    t4: ElectrodeStatus;
    o1: ElectrodeStatus;
    o2: ElectrodeStatus;
  };
  isArtifact: boolean;                // Флаг детекции моргания или сжатия мышц
}

export type ElectrodeStatus = 'good' | 'fair' | 'poor' | 'disconnected';
```

## 7. Operating Rules & Integrity Mandate for AI Agents (Правила для агентов)

Каждый агент, работающий в репозитории FocusGlass, обязан неукоснительно соблюдать следующие системные правила:

### 7.1 Мандат инженерной честности (Integrity Mandate)
- **ЗАПРЕЩЕНО создавать фейковые/пустышечные заглушки (facade implementations)**, имитирующие работу без реальной логики.
- **ЗАПРЕЩЕНО хардкодить статические числа вместо расчетов**: генератор симуляции обязан честно рассчитывать тригонометрические суперпозиции частот (Альфа, Бета, Тета) с реальным фазовым дрейфом и шумом.
- **Слайдеры и переключатели обязаны реально изменять поведение системы**: изменение порога затемнения в настройках обязано мгновенно пересчитывать степень затемнения оверлея.
- **Независимый аудит (Forensic Audit)**: Любая попытка срезать углы или сфабриковать результаты тестов будет немедленно заблокирована аудитором.

### 7.2 Стандарты качества кода (Engineering Standards)
- **Rust Core**:
  - Код обязан компилироваться без `warning`-сообщений (`cargo clippy -- -D warnings`).
  - Все ошибки ввода-вывода и FFI обязаны обрабатываться через явные типы `Result<T, AppError>`. Никаких бесконтрольных `.unwrap()` в продакшн-путях.
  - Поддержка многопоточности с неблокирующим считыванием телеметрии через каналы `crossbeam` или `tokio::sync::mpsc`.
- **React 19 & TypeScript**:
  - Строгий режим TypeScript (`"strict": true`). Никаких типов `any`.
  - Модульные стили через утилиты Tailwind CSS v4 и строгие CSS-токены.
  - ЭЭГ-осциллограф рендерится исключительно на Canvas 2D в цикле `requestAnimationFrame`, исключая ререндеры дерева компонентов React со скоростью 250 Гц.
- **Кроссплатформенность**:
  - Код фронтенда обязан одинаково безупречно работать как внутри Tauri WebView на Windows 11, так и в браузере при локальной разработке на macOS.
  - Вызовы Tauri API экранируются через защитный мост `tauriBridge.ts`, гарантирующий корректную работу симулятора даже в обычном браузере.

### 7.3 Рабочий процесс: git и сборка
- **Репозиторий обновляется автоматически извне.** Перед каждым промтом хук `UserPromptSubmit` (`.claude/settings.json`) делает `git pull --ff-only`, результат приходит в контекст строкой `[git pull] ...`. Если pull упал (конфликт, расхождение веток, нет сети) — сначала сообщить пользователю и не работать поверх устаревшего дерева.
- Перед коммитом и пушем — повторный `git pull --ff-only`.
- **Сборка, запуск и тесты под Windows выполняются на тестовой Windows-виртуалке**, а не на Linux-хосте разработчика. Доступы к ней в репозиторий **не коммитятся**. Как собирать и что там стоит — [docs/WINDOWS_BUILD.md](docs/WINDOWS_BUILD.md), скрипт — `scripts/windows/build.ps1`.
- Схема временная: позже переезжаем на локальный GitLab с локальным CI/CD, сборка уйдёт в пайплайн.

cd src-tauri && cargo test && cargo clippy -- -D warnings

### 9.4 Управление презентационным симулятором (Интерактивные горячие клавиши)
Во время демонстрации приложения активны следующие глобальные клавиши:
- **`1`**: Режим ультра-фокуса ($92\%$) — экран абсолютно прозрачен, HUD светится неоновым цианом.
- **`2`**: Нормальный рабочий поток ($72\%$) — стандартное рабочее состояние.
- **`3`**: Дрейф внимания и прокрастинация ($38\%$) — демонстрация срабатывания БОС: экран плавно затеняется виньеткой.
- **`4`**: Артефакт мимики / моргания — индикатор артефакта, временная фиксация прозрачности.
- **`Пробел`**: Пауза / Возобновление сеанса БОС.
- **`Ctrl+Shift+G`** (или кнопка в HUD): Развернуть / Свернуть панель управления и настроек.
