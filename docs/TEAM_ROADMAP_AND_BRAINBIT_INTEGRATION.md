# План развития FocusGlass (MindTint), роли команды П5 и интеграция с BrainBit

Этот документ описывает **реальное текущее состояние репозитория**, небольшие проверяемые задачи для участников команды П5 (можно сразу перенести на доску Jira `focus-glass.atlassian.net` или Яндекс.Доску) и точную схему подключения физического нейрообруча **BrainBit (`neurosdk2` + `EmotionalMath`)**.

---

## 1. Аудит текущего состояния (на 30.10.2026)

### Что уже реально работает и проверено сборкой / тестами
- **Сборка и тесты**: `npm run build` (`tsc && vite build`) и `npm test` (**63 теста** по 5 уровням, включая прямые тесты модулей `src/services/*`) проходят полностью.
- **Десктопная оболочка (`src-tauri/`)**: Tauri v2 под Windows 11 (NSIS), прозрачное окно поверх всех окон, команда сквозного клика `set_click_through`, глобальный хоткей возврата `Ctrl+Shift+G`.
- **Честное ядро БОС (`src/services/biofeedbackEngine.ts`)**:
  - Мгновенный отклик на изменение всех настроек в реальном времени (порог, режим `Концентрация` / `Релаксация`, окно сглаживания, макс. затемнение, радиус размытия).
  - Заморозка прозрачности на артефактах моргания/мимики (`isArtifactFrozen`, длительность ЭОГ-всплеска 240 мс).
  - Безопасная пауза затемнения при отходе сухого электрода от кожи (`isContactPaused`, сопротивление `> 2000 кОм`).
  - Калибровка базовой линии (`6 сек` демо / `30 сек` протокол БОС) с отсевом артефактов и обрывов контакта для обоих режимов (`concentration` и `relaxation`).
- **Спектральная математика и CSV-конвейер (`src/services/spectralMath.ts`)**:
  - Расчёт спектра мощностей ($\delta, \theta, \alpha, \beta, \gamma$) с окном Ханна на частоте 250 Гц по **биполярным отведениям `T3 − O1` и `T4 − O2`** (именно такую дифференциальную схему использует `EmotionalMath` в BrainBit SDK для подавления синфазной помехи лобного референта).
  - Импорт сырых 4-канальных CSV (`timestamp,t3,t4,o1,o2` из `MNE-Python`) и экспорт посекундных отчётов сессий в CSV.
- **Аудио-БОС (`src/services/audioBiofeedback.ts`)**: реальный синтез мягкого розового шума (`1/f`, фильтр НЧ 420 Гц) на Web Audio API без нагрузки на CPU.

### Что сейчас является симуляцией (и помечено в UI явно)
- В режиме **«Симулятор»** сигнал 4 каналов и сопротивление электродов (`115–135 кОм`) генерируются математически.
- В режиме **«BrainBit BLE»** генерация синтетики останавливается и выводится честный статус `SDK не подключён` (фейковые имена Bluetooth-устройств убраны).

## 2. Архитектура подключения реального BrainBit (2 практичных пути)

Точка приёма живых пакетов в приложении **уже готова**: метод `simulationEngine.ingestHardwarePacket(packet: EEGTelemetry)` в `src/services/simulationEngine.ts`.

У команды есть **два совместимых варианта** интеграции `neurosdk2` + `EmotionalMath` (выберите тот, который быстрее собрать на вашем Windows-ноутбуке с гарнитурой):

### Вариант А (Рекомендуемый для быстрого MVP): Python-сайдкар (`pyneurosdk2` + `pyem-st-artifacts`) → WebSocket
ООО НМФ «Нейротех» официально публикует готовые Python-колёса (`pyneurosdk2`, `pyem-st-artifacts`), которые ставятся через `pip` без ручной возни с C ABI и заголовочными файлами DLL, и идеально стыкуются со стеком аналитики на Python (`MNE-Python`).

1. Установить пакеты на Windows ПК с Bluetooth LE:
   ```bash
   pip install pyneurosdk2 pyem-st-artifacts websockets
   ```
2. Пайплайн Python-процесса (`scripts/brainbit_bridge.py`):
   - `Scanner([SensorFamily.LEBrainBit])` → поиск и подключение к `BrainBitSensor`.
   - Чтение `BrainBitResistData` (`O1, O2, T3, T4` в Омах; перевести в кОм делением на `1000`; норма контакта сухого электрода `< 2000 кОм`).
   - Чтение `BrainBitSignalData` (250 Гц, значения в Вольтах → умножить на `1e6` для мкВ).
   - Передача биполярных отведений `RawChannels(left_bipolar = T3 - O1, right_bipolar = T4 - O2)` в `EmotionalMath`:
     - `math.push_data(raw_channels)`
     - `math.process_data_arr()`
     - Чтение `MindData` (`rel_attention`, `rel_relaxation`), `SpectralDataPercents` и `math.is_both_sides_artifacted()`.
   - Отправка JSON-пакета `EEGTelemetry` по локальному `ws://127.0.0.1:8765` в FocusGlass (где клиент вызывает `simulationEngine.ingestHardwarePacket(packet)`).

### Вариант Б (Нативный единый `.exe`): Rust FFI в `src-tauri/src/bci/`
- Подключить `neurosdk2.dll` и `em_st_artifacts.dll` через крейт `libloading` в `src-tauri/`.
- В отдельном потоке подписываться на колбэки `SignalData` / `ResistData`, эмитить событие `app_handle.emit("brainbit-telemetry", packet)` во фронтенд и обновить `get_device_status()` в `src-tauri/src/commands.rs`, чтобы возвращалось `device_source: "bluetooth"` при реальном коннекте.

## 3. Небольшие проверяемые задачи для участников команды П5

Каждая задача изолирована, занимает **1.5–3 часа** и не блокирует остальных участников:

1. **Системная аналитика ЭЭГ и методология БОС (Анна Соколова)**:
   - [ ] Подготовить 2–3 эталонных `.csv` файла (`timestamp,t3,t4,o1,o2` на 250 Гц) в `MNE-Python` (спокойное бодрствование с закрытыми/открытыми глазами, счёт в уме, моргания) для проверки `CSV-записи ЭЭГ` в FocusGlass.
   - [ ] Проверить и уточнить закон отображения дефицита в прозрачность (сейчас линейный `deficit = (threshold - metric) / threshold`; проверить в Python/statsmodels, нужен ли гистерезис 3–5% или сигмоидальная мёртвая зона у порога, чтобы экран не «дышал» на границе порога).
   - [ ] Зафиксировать критерии качества контакта сухих электродов BrainBit (`хороший < 500 кОм`, `допустимый 500–2000 кОм`, `обрыв > 2000 кОм`).

2. **Ядро БОС и интеграция EmotionalMath (Данил Омелечко)**:
   - [ ] Настроить параметры `MathLibSetting` / `ArtifactDetectSetting` библиотеки `EmotionalMath` под частоту 250 Гц и окно БПФ BrainBit.
   - [ ] Сопоставить выходные метрики `MindData.rel_attention` / `rel_relaxation` с пороговой шкалой `FocusGlass` на реальном обруче.

3. **Bluetooth LE и системные окна Tauri (Роман Урюпин)**:

## 4. Команды быстрой проверки перед коммитом

```bash
# 1. Установка зависимостей
npm install

# 2. Прогон всех 63 тестов (Tiers 1–4 + тесты реальных сервисов src/)
npm test

# 3. Строгая проверка типов TypeScript и продакшн-сборка фронтенда
npm run build

# 4. Локальный запуск в браузере (работает без Rust и без гарнитуры)
npm run dev

# 5. Нативный запуск на Windows 11 (требуется Rust + WebView2)
npm run tauri dev
```
