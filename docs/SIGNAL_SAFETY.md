# Поведение при недостоверном или пропавшем сигнале

FocusGlass — учебное приложение, а не средство диагностики, лечения или контроля допуска к работе. Значения «Focus» и «Calm» — программные индексы, не измерения продуктивности, стресса или профессиональной пригодности.

## Приоритеты

1. Потеря контакта хотя бы одного электрода или некорректная целевая метрика снимает затемнение, размытие и звук. Окно сглаживания очищается.
2. Артефакт при пригодном контакте сохраняет предыдущее состояние обратной связи. Он не имеет приоритета над потерей контакта.
3. В режиме Bluetooth отсутствие новых пакетов в течение 1500 мс переводит обратную связь в безопасное состояние. Для этого используется местное монотонное время получения, а не время внутри пакета.
4. После таймаута повторное уведомление не посылается до нового пакета. Пакет проверки сопротивления не считается ЭЭГ. Локальное воспроизведение и симулятор не запускают этот сторож.

1500 мс — консервативная программная настройка для обнаружения остановки потока, не предел производителя и не физиологический норматив. Её нужно проверить на реальном BLE-подключении и при уходе приложения в трей. Проверка выполняется таймером движка; при блокировке JavaScript-потока она произойдёт только после его возобновления. Независимого нативного watchdog пока нет.

Событие таймаута помечает контакт как непригодный для обратной связи. Это не утверждение, что электрод физически оторвался: причиной может быть BLE, SDK или задержка обработки. Исторические значения индекса остаются историческими; по ним нельзя считать текущее состояние человека.

## Статистика и восстановление

Сторож не создаёт искусственный отсчёт ЭЭГ, не добавляет время «фокуса», не увеличивает число отвлечений и не записывает уведомление в сырой буфер. При возобновлении потока DSP и сглаживание начинают работу без предшествующей таймауту истории. Калибровка не заменяется автоматически.

`durationSeconds` в текущем движке — накопленное время принятых отсчётов, а не полное время между началом и концом сессии. `artifactCount` — число помеченных отсчётов, не число отдельных морганий. Эти величины нельзя выдавать за долю продуктивного рабочего дня.

## Проверка

```sh
npm ci
npm test
npx tsc --noEmit
```

`tests/tier1_features/signalSafety.test.ts` проверяет потерю контакта одновременно с артефактом, NaN/Infinity и выход метрики за диапазон, граничное время таймаута, повторное подключение, пустые пакеты, режим посадки, локальную запись и вызов через таймер.

Перед выпуском установщика отдельно проверить на Windows с BrainBit: отключение BLE во время затемнения и звука; возвращение из сна; работу из трея; повторное подключение; начало и конец проверки посадки. Автотесты не заменяют эти проверки.

## Ограничения применения

- Только добровольное использование с понятным включением и выключением. Не скрытое наблюдение за сотрудниками и не оценка людей по ЭЭГ.
- Не использовать при вождении, диспетчеризации, управлении оборудованием и других задачах, где перекрытие экрана опасно.
- Не заявлять, что сглаживание, виньетка или частота обновления сами по себе доказывают безопасность для зрения или фоточувствительных пользователей.
- При дискомфорте остановить сессию; не продолжать работу сквозь размытый текст. Нужны отдельные ограничения для несовершеннолетних и людей с фоточувствительностью.
