# FocusGlass: Руководство по архитектуре, UI и интеграции бэкенда

> **Документация для бэкенд-разработчиков и системных интеграторов**  
> **Проект**: FocusGlass (ФокусГласс) / НМФ «Нейротех»  
> **Целевое устройство**: Нейрообруч BrainBit (4 сухих электрода: T3, T4, O1, O2, 250 Гц)  
> **Версия**: 2.0 (Figma Redesign)

---

## 2. Экраны приложения: кнопки, параметры и вызовы

### 2.1 Мастер первого запуска (`OnboardingWizard`)

Состоит из 5 последовательных экранов, управляемых состоянием `onboardingStep`:

1. **`01 Приветствие` (`welcome`)**:
   - `Подключить BrainBit` (кнопка оранжевая): переводит мастера на шаг `connect`.
   - `Демо без обруча` (кнопка темная): вызывает `updateSettings({ deviceSource: 'simulator' })` и переводит на шаг `connect`.
2. **`02 Подключение обруча` (`connect`)**:
   - `Искать снова`: вызывает `tauriBridge.scanBrainBitDevices()`, запускает анимацию поиска BLE.
   - Список найденных устройств (`BrainBit-2A41`, `BrainBit-7F03`): выбор активного устройства.
   - `Подключить`: инициирует BLE-соединение, переводит на шаг `sensors`.
   - `Запустить демо-режим`: переключает источник на встроенный 250 Гц симулятор.
   - `Назад`: возврат на шаг `welcome`.
3. **`03 Проверка датчиков` (`sensors`)**:
   - Интерактивная схема головы и электродов (`T3`, `T4`, `O1`, `O2`).
   - Мониторинг сопротивления в кОм: норма 100–800 кОм (зеленый), >800 кОм (желтый), обрыв >2500 кОм (красный).
   - Баннер готовности: активируется при `isContactOk === true` (все 4 датчика имеют контакт).
   - `Далее: калибровка`: переводит на шаг `calibrating`.
4. **`04 Калибровка` (`calibrating`)**:
   - 30-секундный круговой таймер обратного отсчета: вызывает `startCalibration(30)`.
   - Накопление незашумленных пакетов ЭЭГ без артефактов EOG/EMG.
   - `Отменить`: прерывает калибровку вызовом `cancelCalibration()`.
5. **`05 Калибровка завершена` (`done`)**:
   - Отображает персональные рассчитанные метрики:
     - `Ваш фокус (бета-ритм)`: средний baseline уровень в покое (например, 64%).
     - `Ваше спокойствие (альфа-ритм)`: средний baseline уровень (например, 58%).
     - `Рекомендуемый порог`: адаптированный порог срабатывания (например, 55%).
   - `Повторить калибровку`: перезапускает замер.
   - `Начать сессию`: сохраняет персональные настройки и открывает рабочий экран `Сессия`.

### 2.2 Экран «Сессия» (`SessionScreen`, Figma `06`)

Главный рабочий дашборд во время выполнения умственной работы:

- **Переключатель режима (Segmented Pill)**:
  - `Фокус`: `updateSettings({ mode: 'concentration' })` (целевой ритм — Бета 14-30 Гц).
  - `Спокойствие`: `updateSettings({ mode: 'relaxation' })` (целевой ритм — Альфа 8-13 Гц).
- **Круговой спидометр внимания**:
  - Отображает сглаженную текущую метрику (`feedbackState.smoothedMetric`).
  - Статус-бейдж: `Внимание в норме` (зеленый) или `Фокус ниже порога` (янтарный).
- **График тренда за 10 минут**:
  - Сглаженная линия с заливкой градиентом.
  - Горизонтальная пунктирная линия порога (`settings.threshold`).
  - Круглые маркеры в точках просадок внимания ниже порога (`isDip`).
- **Слайдер «Порог срабатывания»**:
  - Диапазон: 10% — 95% (шаг 1%).
  - Вызывает `updateSettings({ threshold: value })`. Изменение применяется мгновенно без перезапуска сессии.
- **Карточка «Как подсказывать»**:
  - Показывает текущий пресет (например, «Плавное затемнение до 60%»). Клик открывает экран `Настройки`.
- **4 информационные карточки сессии**:
  - `Длительность`: таймер активной сессии (ММ:СС).
  - `Время в фокусе`: процент времени, когда показатель был выше порога.
  - `Отвлечения`: счетчик событий падения ниже порога.
  - `Средний фокус`: интегральный средний балл за сессию.
- **Панель действий снизу**:
  - `Пауза / Продолжить`: вызывает `togglePause()`, приостанавливает поток симуляции и аудио.
  - `Завершить сессию`: вызывает `finishSession()`, сохраняет запись в локальную историю и открывает экран `Итоги сессии`.
  - `Свернуть в мини-панель`: вызывает `setViewMode('hud')`, окно переходит в компактный плавающий оверлей.
  - Подсказка хоткея `Ctrl + Shift + F`: мгновенное сворачивание/разворачивание.

### 2.3 Плавающая мини-панель (`FocusBarHUD`, Figma `07`)

Отображается поверх всех окон в режиме `viewMode === 'hud'`:
- Компактная плавающая капсула 340px с полупрозрачным фоном (`backdrop-blur-2xl`).
- Перетаскиваемый заголовок (`data-tauri-drag-region`).
- Живой процент внимания (например, `78%`) + статус (`Внимание в норме` / `Фокус ниже порога`).
- Линейная шкала прогресса с вертикальной засечкой порога.
- Индикатор датчиков (`Датчики 4/4`).
- Кнопка `Развернуть` / иконка `Maximize`: возврат в полный дашборд.

### 2.4 Экранный светофильтр БОС и подсказка (`BiofeedbackOverlay`, Figma `08`)

- При падении метрики ниже порога экран плавно затеняется со сглаживанием 600 мс (`backgroundColor: rgba(11, 15, 26, opacity)`).
- Максимальная глубина затемнения ограничена настройкой `dimmingMaxOpacity` (по умолчанию 60-70%).
- **Всплывающая подсказка (`08 Подсказка`)**:
  - Появляется снизу экрана при зафиксированном отвлечении: *«Внимание снизилось до 42%. Вернитесь к задаче или сделайте короткую паузу.»*
  - Кнопка `Пауза 5 минут`: ставит сессию на паузу и скрывает подсказку.
  - Кнопка `Понятно`: закрывает подсказку для текущего эпизода отвлечения.

### 2.5 Экран «Итоги сессии» (`SessionSummaryScreen`, Figma `09`)

- Открывается после нажатия `Завершить сессию`.
- Содержит:
  - Временной диапазон (`СЕГОДНЯ · 13:40–14:32`).
  - Кнопку `Экспорт CSV`: формирует и скачивает подробный отчет телеметрии сессии.
  - 4 карточки итогов: Длительность, Время в фокусе (с динамикой `+6% к прошлой`), Отвлечения, Средний фокус.
  - Полный график сессии с отмеченными точками просадок и пороговой линией.
  - Блок аналитики: персональное наблюдение на основе данных сессии.
  - Кнопка `Открыть историю`: переход на вкладку `История`.
  - Кнопка `Новая сессия`: сброс счетчиков и старт новой сессии.

### 2.6 Экран «История» (`HistoryScreen`, Figma `10`)

- Недельный столбчатый график: минуты в фокусе по дням недели (`Пн`, `Вт`, `Ср`, `Чт`, `Пт`, `Сб`, `Вс`).
- Карточки аналитики за неделю: `Средний фокус за неделю` (сравнение с прошлой неделей), `Всего в фокусе` (часы, минуты, количество сессий).
- Таблица прошедших сессий: Дата, Длительность, Графический индикатор среднего фокуса (оранжевый при $\ge 65\%$, желтый при $<65\%$), Количество отвлечений, кнопка детального просмотра.
- Кнопка `Экспорт всех сессий`: экспорт всей накопленной истории в CSV.

### 2.7 Экран «Устройство» (`DeviceScreen`, Figma `12`)

- Карточка статуса обруча: Фото устройства, имя (`BrainBit-2A41`), статус подключения, уровень батареи (%), частота (250 Гц).
- Переключатель источника: `Обруч BrainBit` (BLE) vs `Демо-режим` (симулятор).
- Кнопка `Отключить` и `Найти другой обруч`.
- Блок датчиков: 2D-схема расположения T3, T4, O1, O2 с отображением сопротивления в кОм в реальном времени.
- Кнопки `Проверить контакт` и `Повторить калибровку`.
- Карточка `Ваша норма`: отображает дату последней калибровки, индивидуальный базовый фокус, спокойствие и установленный порог.

### 2.8 Экран «Настройки» (`SettingsScreen`, Figma `11`)

Вкладки:
1. **Подсказки**:
   - Выбор стиля индикации: `Плавное затемнение`, `Размытие`, `Только отвлекающие окна`.
   - Слайдер `Максимальное затемнение` (10% — 95%).
   - Слайдер `Скорость реакции` (1 — 10 сек, скользящее окно фильтра).
   - Тумблер `Клики проходят сквозь затемнение` (`tauriBridge.setClickThrough`).
   - Тумблер `Звуковая подсказка` (модулированный розовый шум Web Audio API).
2. **Чувствительность**: математические параметры фильтрации и размер буфера БПФ.
3. **Звук**: настройка генератора шума БОС.
4. **Горячие клавиши**:
   - `Ctrl + Shift + G`: Аварийный сброс сквозного клика (`click-through`).
   - `Ctrl + Shift + F`: Переключение между полноразмерным окном и плавающим HUD.
   - `1`–`5`, `Space`: Пресеты и пауза симулятора.
- Кнопка `Сбросить по умолчанию` и кнопка `Сохранить`.

## 3. Спецификация IPC команд и событий Tauri (Rust <-> Frontend)

### 3.1 Команды Rust (`tauri::command`)

#### 1. `set_click_through`
```rust
#[tauri::command]
fn set_click_through(window: tauri::Window, enabled: bool) -> Result<bool, String>
```
- **Аргументы**: `{ enabled: boolean }`
- **Действие**: При `true` на Windows устанавливает флаги `WS_EX_TRANSPARENT | WS_EX_LAYERED`. Клики мыши проходят сквозь окно насквозь в фоновые приложения (IDE, браузер). При `false` восстанавливает интерактивность окна.

#### 2. `set_overlay_mode`
```rust
#[tauri::command]
fn set_overlay_mode(window: tauri::Window, enabled: bool) -> Result<bool, String>
```
- **Аргументы**: `{ enabled: boolean }`
- **Действие**: Переключает геометрию окна между полноразмерным окном дашборда и прозрачным экранным холстом оверлея.

#### 3. `get_device_status`
```rust
#[tauri::command]
fn get_device_status() -> Result<DeviceStatus, String>
```
- **Возвращает**: Состояние BLE-соединения, уровень заряда батареи, имя подключенного обруча.

#### 4. `scan_brainbit_devices`
```rust
#[tauri::command]
async fn scan_brainbit_devices() -> Result<BrainBitScanResult, String>
```
- **Возвращает**: Список найденных в радиусе BLE устройств с адресами и уровнем RSSI.

#### 5. `toggle_always_on_top`
```rust
#[tauri::command]
fn toggle_always_on_top(window: tauri::Window, enabled: bool) -> Result<bool, String>
```
- **Аргументы**: `{ enabled: boolean }`
- **Действие**: Закрепляет окно поверх всех остальных окон Windows (`HWND_TOPMOST`).

#### 6. `minimize_window` и `close_window`
- Стандартные оконные операции для кастомного тайтлбара.

### 3.2 События Tauri (`app.emit`)

#### 1. `brainbit-telemetry`
Потоковое событие телеметрии (250 Гц или пачками):
```typescript
interface EEGTelemetry {
  timestamp: number;
  rawChannels: { t3: number; t4: number; o1: number; o2: number };
  concentration: number; // 0 - 100%
  relaxation: number;    // 0 - 100%
  signalQuality: { t3: boolean; t4: boolean; o1: boolean; o2: boolean };
  resistanceKOhm?: { t3: number | null; t4: number | null; o1: number | null; o2: number | null };
  isArtifact: boolean;   // true при моргании (EOG) или сжатии челюстей (EMG)
}
```

#### 2. `click-through-disabled`
Эмитится из Rust при нажатии глобального хоткея `Ctrl+Shift+G`, чтобы уведомить React-состояние о возврате фокуса ввода.

## 4. Результаты адаптивного тестирования на различных разрешениях

Интерфейс протестирован на ключевых десктопных разрешениях:

| Разрешение | Соотношение | Поведение интерфейса |
|---|---|---|
| **1280 × 800** | 16:10 | Базовое эталонное разрешение Figma. Сайдбар 220px, полная 2-колоночная сетка дашборда, элементы размещаются без скролла. |
| **1920 × 1080** | 16:9 | Full HD: контент центрируется с максимальной шириной контейнера `max-w-6xl`, увеличиваются отступы, графики растягиваются плавно по ширине. |

| **1024 × 680** | ~3:2 | Минимально поддерживаемое окно: сетка карточек метрик плавно перестраивается в 2 колонки, сайдбар сохраняет доступ ко всем разделам. |
