# FocusGlass

Учебный проект по кейсу ООО НМФ «Нейротех» (Таганрог).

FocusGlass — десктопное приложение биологической обратной связи для нейрообруча **BrainBit**. Обруч снимает ЭЭГ с 4 каналов (T3, T4, O1, O2), приложение считает индекс концентрации и показывает поверх экрана полупрозрачный «стеклянный» оверлей: когда внимание падает, экран плавно затемняется, когда фокус возвращается — снова становится прозрачным. Клики и клавиатура проходят сквозь оверлей, так что работать он не мешает.

## Что сейчас есть

Это MVP к защите кейса: интерфейс в стиле Liquid Glass и экран настроек (порог концентрации, режим «Фокус» / «Релакс», максимальное затемнение, выбор устройства). Пока без настоящего обруча — данные ЭЭГ генерирует встроенный симулятор.

## Стек

- **Tauri v2 + Rust** — десктопная оболочка и бэкенд
- **React + TypeScript + Vite** — интерфейс
- **Tailwind CSS** — стили Liquid Glass
- Основная платформа — **Windows 11**

Подробная архитектура и план — в [AGENTS.md](AGENTS.md).
