# FocusGlass (MindTint)

Проект команды **П5** трека **ЮФУ.Про 2026** по кейсу компании **ООО НМФ «Нейротех»** (г. Таганрог).

**FocusGlass** (в презентации кейса также **MindTint**) — легковесное десктопное приложение пассивной биологической обратной связи (ЭЭГ-БОС) под беспроводной нейроинтерфейс **BrainBit** (4 сухих электрода `T3, T4, O1, O2` · 250 Гц). Приложение работает поверх любых рабочих окон в режиме сквозного клика: при снижении концентрации (`β`-ритм) или росте напряжения (`α`-ритм) экран плавно затеняется по периферии, мягко помогая вернуть фокус без всплывающих окон и отрыва от задачи.

---

## Честный статус MVP (на 30.10.2026)

| Подсистема | Статус | Примечание |
|---|---|---|
| Десктопная оболочка **Tauri v2 + Liquid Glass UI** | Работает | Прозрачное окно поверх окон ОС, сквозной клик (`WS_EX_TRANSPARENT`), возврат управления по `Ctrl+Shift+G`, интерфейс `RU / EN` |
| Математическое ядро БОС (`src/services/biofeedbackEngine.ts`) | Работает | Живой отклик на порог, сглаживание (0.5–5 с), режимы `Концентрация` / `Релаксация`, заморозка прозрачности на ЭОГ/ЭМГ артефактах моргания, пауза при потере контакта электрода |
| Персональная калибровка + журнал сессий + CSV | Работает | Экспресс-калибровка (6 с) и полный протокол (30 с), расчёт спектра биполярных отведений `T3−O1` / `T4−O2`, импорт 4-канальных CSV (совместимо с `MNE-Python`) и экспорт отчётов |
| Аудио-БОС (`src/services/audioBiofeedback.ts`) | Работает | Реальный синтез мягкого розового шума (`1/f`, фильтр 420 Гц) через Web Audio API пропорционально дефициту фокуса |
| Источник живого ЭЭГ (250 Гц) | Симуляция / CSV | Встроенный 250 Гц генератор ритмов `α/β/θ` + авто-сценарий демонстрации (`Авто-демо 40с`) + воспроизведение CSV |
| Прямая интеграция **BrainBit BLE (`neurosdk2` + `EmotionalMath`)** | Этап 2 | Слот `ingestHardwarePacket` и диагностика готовы; в режиме `BrainBit BLE` симуляция честно отключается до линковки SDK |

## Стек

- **Tauri v2 + Rust** — нативная десктопная оболочка (Windows 11 / кроссплатформенный dev-режим)
- **React 19 + TypeScript + Zustand + Vite 6** — клиентский интерфейс и 60 FPS Canvas-осциллограф
- **Tailwind CSS v4** — дизайн-система Liquid Glass

## Запуск и проверка

```bash
# Установка зависимостей
npm install

# Запуск в браузере (с интерактивным превью сквозного режима и симулятором)
npm run dev

# Запуск всех 63 автотестов
npm test

# Продакшн-сборка фронтенда
npm run build

# Запуск десктопного окна Tauri (при установленном Rust toolchain)
npm run tauri dev
```
