# FocusGlass

Учебный проект команды П5 (ЮФУ.Про) по кейсу ООО НМФ «Нейротех» (Таганрог).

FocusGlass (MindTint) — десктопное БОС-приложение для нейрообруча **BrainBit** (4 сухих электрода: `T3`, `T4`, `O1`, `O2`, 250 Гц). Приложение отслеживает выбранную метрику («Концентрация» по β-ритму или «Релаксация» по α-ритму) и управляет сквозным экранным оверлеем: при падении показателя ниже порога (или при превышении при инверсии реакции) экран плавно затеняется, при возврате фокуса — снова становится прозрачным. Мышь и клавиатура проходят сквозь оверлей (`click-through`); панель управления возвращается по `Ctrl+Shift+G` или из системного трея.

## Текущий статус (MVP)

**Реализовано и работает:**
- **Кроссплатформенная оболочка Tauri v2 и системный трей:**
  - **Windows**: главное окно `main`, полноэкранное окно `overlay` на основном мониторе со светофильтром и HUD (мышь проходит сквозь фон и при click-through — сквозь HUD), системный трей (открыть панель, вкл/выкл оверлей, click-through HUD, выход), глобальный хоткей `Ctrl+Shift+G` и установщик NSIS (`*-setup.exe`).
  - **Linux**: композитные окна `overlay-*` на всех мониторах и плавающий HUD, сборка DEB / AppImage; подробнее в [docs/LINUX_BUILD.md](docs/LINUX_BUILD.md).
- **Размытие чужих окон (Windows):** `src-tauri/src/screen_blur.rs` снимает уменьшенную в 6 раз копию экрана под оверлеем через GDI и отдаёт её по `http://fgcap.localhost/frame` только окну `overlay`, которое рисует размытый фон пропорционально дефициту фокуса (настройка «Screen Blur Strength», 0–32 px; включается с 4 px, выключается ниже 2 px; 0 — только затемнение). На Linux и в браузере используется `backdrop-filter`.
- **Умная блокировка отвлечений (Windows):** `src-tauri/src/distraction.rs` отслеживает активное окно через `SetWinEventHook`; в режиме «Distracting Apps Only» затемняется только активное окно, если имя процесса или заголовок совпали со списком (Telegram, YouTube и т. п.).
- **Расчёт БОС-обратной связи** (`src/services/biofeedbackEngine.ts`): скользящее окно сглаживания, линейный дефицит относительно порога, режимы «Концентрация» / «Релаксация», инверсия реакции (`invertReaction`), заморозка прозрачности на время артефактов моргания/ЭМГ (~240 мс) и пауза затемнения при потере контакта электродов.
- **Индивидуальная калибровка базового уровня** (10 с / 30 с): робастная медиана с повышенным весом второй половины записи, оценка утомления и отображение отклонения от личной нормы в диапазонах `−100…+100` / `0…100%` (Baseline = 0).
- **Локальный плеер предзаписанных ЭЭГ** в CSV/TSV/TXT/JSON: воспроизводит сырые `T3/T4/O1/O2` через тот же DSP/БОС-конвейер без физического обруча; доступны пауза, перемотка и скорость `0.25×…4×`.
- **Проектная проверка сопротивления `T3/T4/O1/O2`** (порог `≤800 кОм`, не норматив производителя), нормализация явно обозначенных `Ω`/`kΩ` в локальном EEG-плеере и отбраковка артефактов; методика и оговорки: [docs/EEG_SIGNAL_QUALITY.md](docs/EEG_SIGNAL_QUALITY.md).
- **Аудио-БОС на Web Audio API**: фильтрованный розовый шум с регулируемой максимальной громкостью (`audioVolume`) и модуляцией по дефициту фокуса.
- **История сессий в SQLite и CSV-экспорт:** `src-tauri/src/storage.rs` хранит сессии в `focusglass.sqlite3` (в браузере — `localStorage`), активная сессия автосохраняется каждые 5 секунд и при выходе; доступна выгрузка в CSV.
- **Подключение к физическому BrainBit по BLE (NeuroSDK2):** `src-tauri/src/bci/` динамически подгружает `neurosdk2-x64.dll` (загружается через `scripts/fetch-neurosdk2.ps1` в локальный `src-tauri/vendor/`) без зависаний UI: сканирование BLE-ободков, подключение и мониторинг заряда батареи, **режим проверки посадки ободка (`CommandStartResist`)** с живыми значениями импеданса `T3/T4/O1/O2` (кОм), подсказками по лобному референту / волосам / дужкам и 3-секундной проверкой стабильности (порог `≤800 кОм`, хорошо `≤500 кОм`), а также поток ЭЭГ 250 Гц (`CommandStartSignal` -> `brainbit-raw-batch`) через встроенный конвейер `EEGSignalProcessor` + `BiofeedbackEngine` (включая ~240 мс заморозку при артефактах EOG/EMG; также поддерживается внешний IPC-канал `brainbit-telemetry` для `EmotionalMath`). Если библиотека SDK не найдена, приложение честно сообщает об этом и не подменяет сигнал симуляцией.
- 4-канальный Canvas-осциллограф (60 FPS), компактный HUD («шкала-столбик») и дашборд; типизированные ошибки Rust-ядра (`AppError`).

**Работает в режиме симуляции:**
- Встроенный генератор 250 Гц (`src/services/simulationEngine.ts`) формирует синтетические каналы `T3, T4, O1, O2` (α/β/θ + наводка 50 Гц при обрыве контакта), значения сопротивления сухих электродов (кОм) и пресеты для демонстрации (клавиши `1`–`5`, `Space`).

**Известные ограничения (Windows):**
- Оверлей `overlay` покрывает основной монитор (на Linux оверлеи создаются для каждого монитора).
- Режим «Distracting Apps Only» затемняет только активное окно и без размытия (размытие работает в полноэкранном режиме).
- Пока размытие на Windows активно, окно оверлея исключено из захвата (`WDA_EXCLUDEFROMCAPTURE`), чтобы не попадать в собственный снимок (~5 FPS), поэтому на скриншотах и при демонстрации экрана затемнение и HUD в эти моменты не видны.

## Стек

- **Tauri v2 + Rust (edition 2024)** — окна, трей, хоткеи, IPC, SQLite (`rusqlite`), каналы (`crossbeam-channel`), WinAPI (`windows`) / GTK (`gtk` на Linux)
- **React 19 + TypeScript + Vite 6 + Zustand** — интерфейс и логика БОС
- **Tailwind CSS v4** — стили интерфейса

## Запуск и проверка

```bash
# Установка зависимостей
npm install

# Веб-режим (симулятор в браузере)
npm run dev

# Десктопный режим Tauri (требуется установленный Rust)
npm run desktop:dev

# Сборка для текущей ОС (Windows: NSIS; Linux: DEB / AppImage)
npm run desktop:build

# Только нативный бинарник, без установщика
npm run desktop:build:binary

# Проверка типов и сборка фронтенда
npx tsc --noEmit
npm run build

# Прогон автотестов фронтенда (Node 20+)
npm test

# Тесты и линтер Rust-ядра
cd src-tauri && cargo test && cargo clippy --all-targets -- -D warnings
```

Платформенный конфиг Tauri выбирается автоматически, отдельные ветки для ОС
не нужны. Зависимости и ограничения Linux: [docs/LINUX_BUILD.md](docs/LINUX_BUILD.md).
Сборка Windows выполняется на Windows: [docs/WINDOWS_BUILD.md](docs/WINDOWS_BUILD.md).

Изображения устройства взяты с официального сайта [brainbit.com](https://brainbit.com).
