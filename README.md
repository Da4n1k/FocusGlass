# FocusGlass

Учебный проект команды П5 (ЮФУ.Про) по кейсу ООО НМФ «Нейротех» (Таганрог).

FocusGlass (MindTint) — десктопное БОС-приложение для нейрообруча **BrainBit** (4 сухих электрода: `T3`, `T4`, `O1`, `O2`, 250 Гц). Приложение отслеживает выбранную метрику («Концентрация» по β-ритму или «Релаксация» по α-ритму) и управляет прозрачностью сквозного экранного оверлея: при падении показателя ниже порога экран плавно затеняется, при возврате фокуса — снова становится прозрачным. Клики мыши и ввод с клавиатуры проходят сквозь окно (`click-through`), возврат управления — по `Ctrl+Shift+G`.

## Текущий статус (MVP)

**Реализовано и работает:**
- Десктопная оболочка Tauri v2 (прозрачное окно поверх всех окон, `click-through`, глобальный хоткей `Ctrl+Shift+G`, сборка установщика NSIS под Windows).
- Расчёт БОС-обратной связи (`src/services/biofeedbackEngine.ts`): скользящее окно сглаживания, линейный дефицит ниже порога, переключение режимов «Концентрация» / «Релаксация», заморозка прозрачности на время артефактов моргания/ЭМГ (~240 мс) и пауза затемнения при потере контакта электродов.
- Калибровка индивидуального базового уровня (10 с / 30 с) с отсевом артефактов и участков обрыва контакта.
- Аудио-БОС на Web Audio API (фильтрованный розовый шум с модуляцией громкости по дефициту фокуса).
- Локальное сохранение настроек и истории сессий с выгрузкой в CSV.
- 4-канальный Canvas-осциллограф (60 FPS), компактный HUD («шкала-столбик») и дашборд.

**Работает в режиме симуляции:**
- Встроенный генератор 250 Гц (`src/services/simulationEngine.ts`) формирует синтетические каналы `T3, T4, O1, O2` (α/β/θ + наводка 50 Гц при обрыве контакта), значения сопротивления сухих электродов (кОм) и пресеты для демонстрации (клавиши `1`–`5`, `Space`).

**В разработке (интеграция с физическим BrainBit):**
- Подключение `neurosdk2` (`SignalData`, `ResistData`) и библиотеки `EmotionalMath` (`em_st_artifacts`) в `src-tauri` с передачей пакетов в готовый IPC-канал `brainbit-telemetry`. При выборе режима Bluetooth без подключённого SDK интерфейс честно сообщает об отсутствии потока и не подменяет его симуляцией.

## Стек

- **Tauri v2 + Rust** — управление системным окном, глобальные хоткеи и IPC
- **React 19 + TypeScript + Vite 6 + Zustand** — интерфейс и логика БОС
- **Tailwind CSS v4** — стили интерфейса

## Запуск и проверка

```bash
# Установка зависимостей
npm install

# Веб-режим (симулятор в браузере)
npm run dev

# Десктопный режим Tauri (требуется установленный Rust)
npm run tauri dev

# Проверка типов и сборка фронтенда
npm run build

# Прогон автотестов (Node 20+)
npm test
```

Изображения устройства взяты с официального сайта [brainbit.com](https://brainbit.com).
